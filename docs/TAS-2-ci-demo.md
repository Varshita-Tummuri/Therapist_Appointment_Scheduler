# TAS-2: Therapist sets availability

User story:
As a therapist, I want to set my available hours for specific dates,
so that patients can book only when I am free.

This documentation change demonstrates the GitHub Actions pipeline
associated with the TAS-2 Agile story.

Pipeline stages:

3. Code Quality Check
